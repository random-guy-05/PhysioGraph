# Research directory

Start with [the HF SpO₂/lactate/mortality study](spo2_mimic3_hf_lactate/README.md) for the analysis discussed in the current abstract. Its runnable notebook and model-specific reports are listed there.

Other directories are independent investigations or saved runs. Their folder names identify the topic; their own reports establish scientific status and execution provenance. The repository-level [Start Here page](../START_HERE.md) distinguishes these records from consolidated external snapshots.
