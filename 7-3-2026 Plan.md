# PhysioGraph Plan — July 3, 2026

## Research Question (North Star)

**Can SpO2 signal instability (variability, abrupt changes, sampling behavior, and related signal-quality features) measured in the first 4 hours precede or predict early signs of cardiogenic decompensation in the subsequent 12–24 hours?**

Decompensation outcomes:

- Need for mechanical circulatory support (MCS)
- Rising lactate
- Laboratory markers of organ injury
- Falling urine output
- Rising vasopressor/inotropic score (VIS)

See `PROJECT_GOAL.md` for operational definitions, endpoint hierarchy, and scope guards.

### What’s working

1. **Scientific guardrails** — ~237 automated tests, PROBAST+AI Domain 4 checks, forbidden-column lists, post-landmark SpO2 excluded from features.
2. **SpO2 instability engineering** — `physiograph_colab_core.py`: RMSSD, abrupt jumps, below-90 fraction, sampling density, instability proxy, gap metrics, implausible-value handling.
3. **4h landmark + 24h outcomes in main pipeline** — `derive_labels()` in `pipeline.py`: `mcs_24h_flag`, `pressor_24h_flag`, hypoperfusion/organ-injury flags, `shock_progression_24h_flag` / `target`.
4. **Confounder infrastructure** — Respiratory support (FiO2, vent flags), RRT/dialysis, baseline lactate/hemodynamics, missingness controls (tested).
5. **MIMIC locked comparators** — Ground-truth metrics and frozen lactate-based models (supporting infrastructure, not the primary research question).

### Critical misalignment

The active SpO2 analysis path (`physiograph_colab_core.py`) still uses:

- `HORIZON_HOURS = (48, 72, 96, 168)`
- `PRIMARY_ENDPOINT = "mcs_or_death_168h_flag"`

SpO2 models, OR tables, and descriptive summaries target **MCS/death at 48–168 hours**, not **decompensation at 12–24 hours**. Pipeline 24h labels are not wired as SpO2 analysis endpoints.

## Execution Plan

### Phase 0 — Align code with the research question

**Goal:** Single analysis path; no competing 48–168h MCS/death framing in SpO2 workflow.

| Task | Where | Done when |
|------|-------|-----------|
| Change `HORIZON_HOURS` to `(12, 24)` for SpO2/decompensation work | `physiograph_colab_core.py` | Horizons match `PROJECT_GOAL.md` |
| Set primary endpoints to 12h/24h decompensation flags | `physiograph_colab_core.py` | `PRIMARY_ENDPOINT` and `SECONDARY_ENDPOINTS` use pipeline 24h labels + new 12h labels |
| Wire SpO2 analysis to pipeline labels | `assemble_spo2_analysis_frame`, `fit_spo2_*`, descriptive builders | Models run on `mcs_24h_flag`, `pressor_24h_flag`, `hypoperfusion_24h_flag`, `end_organ_24h_flag`, etc. |
| Demote 48–168h MCS/death to exploratory appendix only | Notebook + colab outputs | Not reported as primary findings |
| Update tests | `tests/unit/test_colab_core.py` | Horizon and endpoint tests pass |

### Phase 1 — Complete missing outcomes

**Goal:** All decompensation components operationalized at 12h and 24h post-landmark.

| Outcome | Work |
|---------|------|
| **12h horizons** | Extend `compute_horizon_outcomes()` and/or `derive_labels()` for 12h flags parallel to 24h |
| **Lactate rise** | Define explicit outcome: e.g. Δlactate ≥ X or crossing threshold 2.0 → 4.0 in outcome window; expose as `lactate_rise_12h/24h_flag` or continuous delta |
| **VIS rise** | Compute VIS from pressor/inotrope events in observation vs outcome windows; `vis_delta_12h`, `vis_delta_24h`, `vis_rise_24h_flag` |
| **Urine output drop** | Extract UO from chart events; trend or delta in 12–24h window; `uo_decline_12h/24h_flag` |
| **Organ injury** | Already partial in pipeline — ensure SpO2 models consume `renal_injury_24h_flag`, `hepatic_injury_24h_flag`, `end_organ_24h_flag` at both horizons |
| **MCS** | Use `mcs_12h_flag` / `mcs_24h_flag` as exploratory endpoint (event-sparse) |

Add schema columns, ground-truth expectations, and unit tests for each new label.

### Phase 2 — SpO2 → decompensation analysis

**Goal:** Answer “predict” with pre-specified endpoint hierarchy.

| Analysis | Method | Primary outputs |
|----------|--------|-----------------|
| **Descriptive** | SpO2 instability metrics by outcome stratum | `spo2_descriptive_summary.csv` |
| **Association** | OR tables with respiratory controls, FDR correction | `spo2_variability_or_tables.csv` |
| **Predictive** | Grouped CV; instability features vs absolute SpO2 baseline | `spo2_model_metrics.csv` |
| **Incremental value** | Nested models: absolute SpO2 → + instability → + respiratory support | ΔAUROC / ΔAUPRC with CI |
| **Endpoint order** | Primary: lactate rise, VIS rise (12–24h). Secondary: UO, organ labs. Exploratory: MCS, composite | One pre-registered table per tier |

Confounders (required in all adjusted models): FiO2 max, vent/support flags, absolute SpO2 level, sampling density, baseline lactate/MAP, age/sex.

### Phase 3 — Lead-time / “precede” analysis

**Goal:** Test whether SpO2 instability moves before other signals.

| Task | Approach |
|------|----------|
| Event ordering | For each stay, timestamp first SpO2 instability event (e.g. abrupt jump cluster, sustained high RMSSD) vs first lactate rise / VIS increase / UO drop |
| Lead-time distribution | Median lead time (minutes) with bootstrap CI |
| Sensitivity | Vary instability definitions; exclude low sampling-density stays |
| Claim guard | Associational only unless explicit causal design — no “SpO2 causes decompensation” language |

Deliverable: `spo2_leadtime_summary.csv` + figure spec for notebook.

### Phase 4 — MIMIC full run (internal validation)

**Goal:** First defensible answer on the research question.

1. Run pipeline on MIMIC → cohort, events, features, labels.
2. Run SpO2 analysis stack on 12h/24h endpoints.
3. Report **all** endpoints including null/fragile results (`fragility_label` for sparse events).
4. Label artifacts: fresh vs cached in `run_status.json`.
5. Update `PhysioGraph_Final_Clean.ipynb` narrative to match `PROJECT_GOAL.md` only.

**Exit criteria:** Every row in `PROJECT_GOAL.md` success criteria addressable from MIMIC outputs (yes/no/underpowered with reason).

### Phase 5 — eICU external check (expect fragility)

**Goal:** Transportability probe, not pooled claims.

1. Run per-dataset analyses separately.
2. Document eligibility and missingness denominators (SpO2 coverage, lactate, pressors, UO).
3. Report calibration drift and AUPRC degradation honestly.
4. Do **not** pool MIMIC + eICU for primary inference.

## Definition of done

The research question is **answered** when we can state, with MIMIC internal validation and eICU external probe:

1. Whether SpO2 instability at 4h **predicts** each decompensation outcome at 12h and 24h, with incremental value over absolute SpO2 and respiratory controls.
2. Whether instability **precedes** lactate/VIS/UO shifts (lead-time evidence or honest null).
3. Which findings are robust vs fragile vs null — with leakage checks passing and outcomes labeled apparent vs validated.

Until Phase 4 completes, the project remains **infrastructure-ready, analysis-incomplete**.
